# InvokeInvoiceSystem
Dependencies:
<ul>
  <li>Cmake</li>
  <li>C++ 20</li>
  <li>vcpkg</li>
  <li>QT6 6.9.1 MSVC</li>
  <li>mongo drivers for vcpkg</li>
</ul>
This is an open-source invoice generator that streamlines the creation of PDF invoices through features including cloud-stored accounts, customizable templates, automated calculations, multi-currency support, and seamless export or email delivery options - all designed for ease of use and integration into existing workflows.
